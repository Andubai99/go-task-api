- 日期：2026-10-01

- 记录方式：建仓前已布置的任务，初始化时补录；不回填 Git 提交时间。
- 任务状态：已通过建仓前的实际运行检查；本记录补录历史完成结果。

## 学习目标

理解 `package main`、程序入口、标准库导入、结构体、字段类型、结构体字面量、短变量声明和格式化输出。

## 题目与要求

1. 定义 `Task` 结构体，包含 `ID int`、`Title string`、`Done bool`。
2. 创建编号为 1、标题为“学习 Go”、尚未完成的任务。
3. 使用 `fmt.Printf("任务：%+v\n", task)` 打印任务。
4. 将任务改为已完成，再打印一次。

## 验收方式

在项目根目录运行程序，预期输出：

```text
任务：{ID:1 Title:学习 Go Done:false}
任务：{ID:1 Title:学习 Go Done:true}
```

确认程序正常退出，并能解释字段的声明、`:=` 和 `%+v` 的作用。

## 相关面试知识

- 结构体聚合相关字段，字段名写在类型前。
- `:=` 在函数内部声明变量，并推断类型。
- 结构体字面量字段跨行书写时需要正确保留逗号。
- 整体重新赋值与通过字段访问修改单个字段的区别。

发布阶段尚无学习者的解题反馈。课程准备时发现终端不能识别 Go，已在被忽略的 `.tools/` 中配置官方 Go 1.27.1，并运行起始程序验证工具可用。

## 完成记录

学习者反馈“好了”后，曾实际读取 `main.go` 并运行。该次程序正常退出，实际输出为：

```text
任务：{ID:1 Title:学习 Go Done:false}
任务：{ID:1 Title:学习 Go Done:true}
```

该次代码先初始化任务，再通过整体重新赋值更新完成状态：

```go
task := Task{
    ID:    1,
    Title: "学习 Go",
    Done:  false,
}
fmt.Printf("任务：%+v\n", task)

task = Task{
    ID:    1,
    Title: "学习 Go",
    Done:  true,
}
fmt.Printf("任务：%+v\n", task)
```
