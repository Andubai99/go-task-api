- 日期：2026-10-01

## 学习目标

理解 `package main`、程序入口、标准库导入、结构体、字段类型、结构体字面量、短变量声明和格式化输出。

## 题目与要求

1. 定义 `Task` 结构体，包含 `ID int`、`Title string`、`Done bool`。
2. 创建编号为 1、标题为“学习 Go”、尚未完成的任务。
3. 使用 `fmt.Printf("任务：%+v\n", task)` 打印任务。
4. 将任务改为已完成，再打印一次。

## 验收方式

在项目根目录运行程序，预期输出：

```text
任务：{ID:1 Title:学习 Go Done:false}
任务：{ID:1 Title:学习 Go Done:true}
```

确认程序正常退出，并能解释字段的声明、`:=` 和 `%+v` 的作用。

## 相关面试知识

- 结构体聚合相关字段，字段名写在类型前。
- `:=` 在函数内部声明变量，并推断类型。
- 结构体字面量字段跨行书写时需要正确保留逗号。
- 整体重新赋值与通过字段访问修改单个字段的区别。
