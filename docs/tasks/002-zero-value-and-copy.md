## 题目与要求

将以下代码加入 `main()` 末尾：

```go

fmt.Printf("零值：%+v\n", empty)

```

运行前先写下预测：

1. `empty` 的 ID、Title、Done 各是什么值？

## 知识复盘

- 未显式赋值时，当前三个字段采用各自的零值：int 为 0，string 为 `""`，bool 为 false。
- `copyTask := task` 复制当前结构体的字段值。复制时原任务的 Done 为 true，随后 `copyTask.Done = false` 修改副本，因此原任务仍为 true。
- 这是字段值复制，不等于递归深拷贝；结构体将来包含指针、切片或 map 时，需要单独观察所引用数据是否共享。
