## 题目与要求

在 `main()` 的已有实验后增加集合练习，创建变量 `tasks`，类型为 `[]Task`，包含以下三条新任务：

| ID | Title | Done |
| --- | --- | --- |
| 1 | 学习 Go | false |
| 2 | 学习 Gin | true |
| 3 | 学习 MySQL | false |

然后完成以下操作：

1. 用 `append` 追加编号 4、标题“写单元测试”、Done 为 false 的任务，保存追加后的切片。
2. 用 `range` 遍历并打印集合中的每一条任务。
3. 用 `len` 打印任务总数。
4. 遍历任务，统计并打印未完成任务的数量。

保留任务 002 的实验和预测注释，集合部分追加在其后，方便复查前后练习。

## 语法提示

- `Task` 是一条任务的类型，`[]Task` 是任务切片的类型。
- 可以使用 `tasks := []Task{}` 创建空切片，也可以在大括号内按已有字段写法填写初始元素。
- `append` 返回追加后的切片，把返回值赋给 `tasks`；后续口述解释为什么需要接收返回值。
- 遍历的基本形式：

```go
for index, item := range tasks {
    // index 是下标，item 是本次迭代的元素值。
    // 在这里打印需要的信息。
}
```

- 不使用下标时可以把 `index` 换成 `_`。Go 不允许声明后未使用的普通局部变量。
- `len(tasks)` 获取元素数量，`item.Done` 是布尔值，可用条件判断筛选。
