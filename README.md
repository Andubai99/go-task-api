## 运行

安装与 `go.mod` 兼容的 Go 后，在仓库根目录运行：

```powershell
go run .
```

当前本机使用未上传的便携式 Go 工具，也可以运行：

```powershell
& '.\.tools\go\bin\go.exe' run .
```

当前编辑快照会产生编译错误；先补齐 `main.go` 中的字段值和字段之间的逗号，再运行。Go 工具、凭据和本地环境配置均不纳入版本管理。

## 课程路线

1. Go 基础：模块、结构体、集合、函数、错误处理。
2. Gin API：CRUD、并发安全、参数校验、中间件。
3. 数据库：分层、接口、MySQL、索引、事务和幂等性。
4. 服务完善：鉴权、并发与取消、测试、配置和优雅退出。
5. 专题实验：语言语义、并发边界、运行时与内存、Redis 缓存。
